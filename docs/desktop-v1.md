## 验收

节奏：小偏移可改善，超限/漏句/不确定区域不移动，下一句可独立恢复，不改变总长。
混音：关闭可旁路效果；开启能测出压缩、混响尾音及随人声变化的伴奏避让；输出有限、峰值受控且与原曲等长。

打包：独立单 EXE，从其他工作目录启动，使用内置模型与 FFmpeg，完成含首次分离的处理。

## 算法边界

起音两两比较时间位置、音高与走势，扣除八度差；互为最优且有足够匹配间隔才接受。整体录音延迟至少需要四个匹配、覆盖三秒、达到两轨较少起音数的 20%；不可靠时整体不移动，且单个孤立匹配不触发局部修正。局部偏差阈值 ±150ms，变时斜率不超过 10%，边界渐变可能使实际修正小于目标。

拒绝的源人声段及参考有声而源持续无声的区域设为禁止区，不跨区插值。节奏层在禁止区逐采样保留原始波形。之后仍经过声码器与可选混音，因此最终成品不保证与输入逐采样相同。禁止区的参考音高修正也关闭，避免依据错句强修。

这是起音/F0 特征算法，没有歌词识别能力；不能保证识别全部漏唱、同旋律错句或错误 F0。目标是保守修正，不是自动逐字贴齐。

混音：75Hz 高通、350Hz 减法 EQ、2.5:1 压缩（最多 6dB）、动态去齿、180Hz / 2.8kHz 加法 EQ，独立自然流行混响与短延时；处理后人声驱动 250–4000Hz 伴奏最多避让 2.5dB，全频最多 0.6dB。总线以 -16 LUFS 为目标，必要时采用 4 倍过采样限制器，再实测并限制真峰值至 -1.5dBTP。限制器的目标压缩量最多约 3dB，不强行达到响度目标。固定预设不保证适合每种音色。

## AI 降噪和 VST3（2026-10-28）

明显数字削波先用 FFmpeg adeclip 修复；随后默认用 DeepFilterNet3 温和档（衰减限制 12 dB、关闭额外后滤波）处理干声，再进入音高提取和节奏匹配。44.1kHz 与模型 48kHz 间使用多相重采样，补偿模型延迟并裁回输入采样数。模型针对语音训练，伴奏串音和房间混响可能保留；削波检测不覆盖所有归一化或有损录音。三首干声的等响度片段和验证数据位于 `out/denoise_research/listen/`，用户认可温和档，传统降噪对照未达到要求。

桌面新增 AI 降噪开关和“混音设置”，可调整人声相对音量（±6 dB）和空间感（0–200%）。VST3 管理界面允许添加文件或文件夹、打开原插件界面，并在关闭后保存和恢复状态。部分插件的状态块不包含自动化参数，因此会额外保存可自动化参数的值并在下次打开时恢复。插件在独立进程运行，不发送音频，不提供实时试听或侧链。Python 3.12 降噪进程和模型随单 EXE 内置，构建方法及模型权重许可的不确定性见 README 和 THIRD_PARTY.txt。
