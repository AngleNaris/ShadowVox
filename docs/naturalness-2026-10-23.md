日期：2026-10-23。状态：代码与素材验证完成，等待人工试听。没有替换现有默认修音策略。

## 本轮变化

- 修正 eval_quality 的时间偏移方向，把修前/修后放在同一参考时间网格，统计共同浊音帧；原始干声使用变时前的 offset。
- 修正 selftest 把 44.1k 采样点除以 16k hop 的错误，以及修前比较时源/参考同时移动的错误；统一使用已知延迟真值。
- 加入 `--pitch-mode natural` 实验：参考音高区域只决定中心偏移，保留源曲线段内形状；短于 100ms 区域不独立估计偏移，但邻接长音的局部过渡可能影响其边缘，不跨清音平滑。默认仍是 frame。
- 生成两首素材九组全长对照、每首三段八秒试听，共 54 段。试听片段按综合响度匹配，无伴奏、压缩和混响。
- 传统引擎为官方 Rubber Band 4.0.0 R3，开启共振峰保留，使用与神经声码器相同的音符中心偏移曲线。官方工具和 COPYING 保存在 tools/vendor，不加入版本控制。

## 独立音符对应与对齐路线调研（2026-10-30）

### 本轮定位与变更

《爱人错过》V2 的节奏强度为 100%、音高力度为 75%。261.81 秒干声中，现有声学/歌词及局部位移筛选通过 35.9 秒；计划可变时区域为 22.2 秒，8 段边界相位回退后为 12.3 秒。旧流程再将其余节奏保护区的音高修正全部清零，导致平均修正量仅 2.49 音分。旧保序验收不能证明修音/节奏效果达标。

完整模式现在分别保留对应关系可信掩码和实际变时路径。音符对应仍须通过声学、局部路径与歌词一致性检查，但不再受变时幅度、最小可变时片段长度及拼接回退限制。修音读取“实际输出时刻→原始演唱时刻→原唱音符时刻”；渲染回退更新实际路径，不能把参考音符误当成已经移到同一时刻。可信掩码在音高中心计算之前生效，不可信位置为零移调。独立对应路径替代完整模式原先额外执行的 F0 DTW；旧 guarded 模式保留原逻辑。草稿与整曲共用映射函数，旧缓存只能沿用已通过的声学证据。

### 更好的对齐候选与下一轮建议

当前音高色度特征容易受跑调影响，歌词锚点又稀疏；继续放宽变时上限不足以解决对应错误。推荐的结构是：歌词序列确认同一句→歌声音素对齐确定字头与元音边界→句内声学细化→连续单调变时。对同一句的快慢、发音拉长和漏唱分别处理；不能直接拿完整原唱歌词强压到实际少唱的干声上。

| 候选 | 已核实能力 | 本项目判断 |
|---|---|---|
| HubertFA | 面向歌声，提供中文歌声 ONNX 模型；推理入口支持 CPU、DirectML、CUDA，需配套歌词/拼音及词典 | 首选小范围验证。较符合本地 Windows 推理路径；仍须测实际字边界、耗时和长元音表现 |
| SOFA | 面向歌声的强制对齐，默认中文拼音词典，提供 ONNX 推理 | 对照候选；先选定匹配模型和词典，不同时引入多个后端 |
| WhisperX | 通过语言专用 wav2vec2 模型细化文字时间戳，含中文默认模型 | 语音能力不能直接视为中文歌声效果，优先级低于歌声模型 |
| Qwen3-ASR / ForcedAligner | 官方 ASR 覆盖音乐/歌声，独立 0.6B 对齐器提供字/词时间戳 | 可用于提高歌词识别覆盖的后续对照；识别歌声的能力不等于已证明其对齐器满足本项目精度 |
| CTW / 音素后验特征 + DTW | 研究针对跨演唱者、音高差或歌词发音的对应 | 是算法方向参考，不能凭论文结果直接替代本机实曲验证 |

### 发现与试验处理

第一版直接以字头对应拟合变时，在重复句尾部出现退步。检查音素记录发现原唱“来”“没”的声母被模型分别延长至约 408ms，前一个字的韵母仅约数毫秒。它们的字头与韵母位移判断相差超过 100ms。直接相信字头，以及逐点前后限速，都可能把局部异常传播到后面的字。

第二版保留完整音频与严格单调时标：韵母任一侧短于 30ms 时跳过该字锚点；字头与韵母位移相差超过 100ms 时只采用韵母；其余字头/韵母均作候选。对整句锚点一次求有约束的最小二乘，输出仍限制在 ±10% 局部伸缩、150ms 位移以内，首尾固定。三个片段的最大计划位移为 141.07、119.45、98.59ms。阈值仅为本轮实验参数，未证明适合所有中文演唱。

变时由 Rubber Band R3 整段一次完成；音高沿“实际输出→原始演唱→参考音符”的独立映射进行 75% register 修正，保留原音区。现有方法对照来自此前真实保守对齐输出。这不是仅替换特征的严格消融实验：新方案的对应筛选、受限拟合、整段渲染均与现有分段流程有区别，不能把全部收益归因于模型本身。

## 保留新对齐，修复修音边界（2026-10-30，用户批准）

用户认可 HubertFA 修订版对齐，要求保持并开始解决修音破损，随后指出“3 秒、10 秒之后”。本轮按上一轮副歌试听的片段内时间定位，范围分别取 2.5–4.5 秒与 9.8–13.5 秒；未将此解释为原曲绝对时间。

### 原因与最小改动

旧 PSOLA 渲染器使用每 10ms 一档的混合系数（0、1/3、2/3、1），在不同相位波形之间直接切档；修音曲线在有效/无效区边界还会突然归零。真实副歌 3.47 秒处从 174.4 音分归零，10.08 秒处从 159.9 音分归零。三段最大的单帧修音指令变化分别为 201.47、214.21、214.25 音分。

仅修改 `src/shadowvox/psola.py`：修音有效区内部使用 50ms smoothstep 包络让目标修正进入/退出，同时按实际采样时间计算连续的波形混合包络。包络不伸进零移调保护区，长音内部仍保持完整修正量；尾部补零控制点，避免最后一帧突然外推归零。平滑后已无有效修正的短区直接旁路，不为零修正引入重合成。未修改 HubertFA 锚点、时间映射、register 音高中心算法或 75% 力度；其他渲染器不受此改动影响。

这修复了明确的边界不连续，但不保证 PSOLA 周期拼接无伪影。修正模块的说明也同步去掉了“气声、辅音、共振峰保留原样”的绝对表述。[Praat 的 overlap-add](https://www.fon.hum.uva.nl/praat/manual/overlap-add.html) 仍依赖源音频周期定位并重排波形。

### 固定输入对照
