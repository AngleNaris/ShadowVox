# 第一轮自然度验证

日期：2026-10-23。状态：代码与素材验证完成，等待人工试听。没有替换现有默认修音策略。

## 本轮变化

- 修正 eval_quality 的时间偏移方向，把修前/修后放在同一参考时间网格，统计共同浊音帧；原始干声使用变时前的 offset。
- 修正 selftest 把 44.1k 采样点除以 16k hop 的错误，以及修前比较时源/参考同时移动的错误；统一使用已知延迟真值。
- 加入 `--pitch-mode natural` 实验：参考音高区域只决定中心偏移，保留源曲线段内形状；短于 100ms 区域不独立估计偏移，但邻接长音的局部过渡可能影响其边缘，不跨清音平滑。默认仍是 frame。
- 生成两首素材九组全长对照、每首三段八秒试听，共 54 段。试听片段按综合响度匹配，无伴奏、压缩和混响。
- 传统引擎为官方 Rubber Band 4.0.0 R3，开启共振峰保留，使用与神经声码器相同的音符中心偏移曲线。官方工具和 COPYING 保存在 tools/vendor，不加入版本控制。

音符中心模式修正更保守，真实素材逐帧误差高于原模式。分段启发式、对齐、段内慢漂移和原声重合成损伤仍有改进空间。未经人工试听，不把任何引擎标为优胜者。

## 2026-10-27 D 基础上的三档修音

用户反馈 D 变化更明显，希望增加修音力度，并明确不能强拉到原唱八度。D 本身没有音高修正。本轮将其相同节奏输入重新送入声码器，增加 J 轻档 45%、K 中档 75%、L 强档 100%；不是对已重合成的 D 二次加工。重跑节奏输入与旧 C 波形最大采样差为 0，D/F 对照人声直接复用。

新增 `register` 实验模式：250ms 以上共同浊音间隙分句，持续 300ms 且稳定的音区关系可独立匹配；不逐帧追随最近八度。残差超过 450c 的位置跳过。约 50ms 平滑音高差及短高斯过渡控制修正，按局部一致性减弱不可靠位置，不再因偏差达到 300c 就把修正归零。该模式只由实验脚本调用，CLI 默认未变。

曾试验音符中心分段及 210ms 移动中心，但在这首素材上前者漏过较多短音、后者强档误差反增，因此本次交付采用 50ms 响应。强档会抑制部分颤音和滑音；没有证明比其他版本更自然。

最终五版共同浊音帧为 15144。相对参考的八度折叠误差（音分）：

| 版本 | 中位数 | 均值 |
|---|---:|---:|
| D 无修音对照 | 49.6 | 82.5 |
| F 旧逐帧修音 | 27.0 | 69.4 |
| J 轻档 | 39.6 | 74.7 |
| K 中档 | 31.6 | 71.5 |

三档中位数与均值均随力度提升而下降；L 中位数略低于 F，但均值仍高于 F，不能概括为全面优于旧版。误差不检测八度，也不是自然度分数。
