为一款名为 ATUNE 的 Windows 桌面修音工具设计一张高完成度的中文主界面设计图。

产品需求：
用户选择原曲和自己的演唱干音，设置输出位置，然后生成与伴奏合并的修音成品。
用户可以调整修音强度，可以开启或关闭混音。
修音应保留演唱者原本所在的音区，不强行拉到原唱的八度；节奏只修正可信范围内的偏移，漏唱或偏差过大的片段不强行对齐。
开启混音时，会进行人声均衡、轻压缩、轻混响、伴奏避让和响度平衡；关闭混音仍会合并伴奏。这些是处理说明，不需要增加逐项调节控件。
需要有开始、取消、真实处理状态、可查看的处理记录，以及完成后打开成品和所在目录的操作。界面状态与可用操作应一致，不虚构检测数据或音频分析结果。

设计要求：
全直角，无圆角。专业音频插件的风格，精致、细腻、克制，有成熟音频软件的设计质感。避免粗大的文字、笨重的控件和粗放的视觉处理。以实用、易读和清楚的操作流程为优先。不要增加产品没有的功能。
请独立完成视觉设计，自行决定布局、配色、字体层级与控件形态。生成一张完整、正面、清晰的应用界面设计图，不是宣传海报，不要展示电脑设备或外部桌面。
